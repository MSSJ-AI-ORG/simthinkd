What you get

Small, fast and easy to own.

One CPU core

About 2 ms per decision with 265,665 parameters. No GPU and no network needed.

Train in seconds

Write your rules as a normal function. The toy task in the README trains on a CPU in about 8 seconds.

NumPy only

Making decisions needs only NumPy. Training adds PyTorch, and the CPU build is fine.

Plugs into your stack

An HTTP server, an MCP server and a LangChain tool come with the package.

Measure your own model

simthinkd bench replays 1,050 recorded Doom states and tells you if a decider answers within one tick.

Checkable

The two bundled deciders are the ones evaluated in the paper. Their SHA-256 hashes are listed so you can check.

Quickstart

One call is one decision.

from simthinkd import Decider

d = Decider("doom-defend")
print(d.decide("seen: Demon left a30 d5 | enemies 1 | sway left | gun ready | ammo25"))
# TURN_LEFT (100%, 1.1 ms)

# train your own from rules, on a CPU
import simthinkd
from simthinkd import toy
d = simthinkd.fit(toy.examples(3000), toy.ACTIONS, goal=toy.GOAL, out="inspection")
